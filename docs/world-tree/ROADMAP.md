## 〇、主题引擎：树的成长弧线（2026-09-01 主人定稿）

**神性 → 人性 → 自我牺牲**：种子/幼苗=无意识自然；成树=母树神性（四族仰望）；巨树=人性觉醒（化身显现，意志漂移=人性的代价）；终局=以"人"的意志做牺牲之选（归还记忆=放弃存在；把希望用在自己身上=爱自己）。

- 化身 = 幸存者灵魂的显现（spec §13.8：树是旧世界最后一个幸存者的梦），巨树阶段引入，与意志漂移（M7）绑定——化身即漂移的镜子
- 关系事件分两级：**仪式级**（巨树身份，四族仰望）+ **亲密级**（需关系≥+2 + 化身场合，四族与"人"对坐——说书人最后的故事/林地民枯萎倾诉/石裔造船之问/野民最后一幅画）
- 7 张明选底色 = 神性与人性的拉扯（非纯代价权衡）
