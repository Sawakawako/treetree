# UI 叙事播报文案

> 主界面事件播报（`log_label` / `race_event_label`）赋值处的固定文案：系统升级消息、各动作的成功/失败反馈、以及动态拼接播报的固定骨架。这些文案与事件正文（各库的 `text`/`dream_text`/`reveal_text` 等）配合显示。
> 来源：`features/ui/main.gd` | 归档日期：2026-09-01

说明：

- 动态文案中的 `%s` / `%d` 为运行时占位符，原文照抄（含占位符）；拼接的来源文本（如图腾 `reveal_text`）另有专档，此处只收录固定骨架。
- HUD 状态行（树液：%s / %s、记忆、信仰、价格、灵魂计数、种族人口·关系行等）为数值界面而非叙事文本，**不归档**。
- 唤醒兜底（读档恢复时重放 `awaken_text`）无独立文案，内容指向四族唤醒文档（见 narrative/04-race-awakenings.md）。

## 灵魂链（复苏/沉魂）

> 河水太远了。

> 它还在岸上。

> 河水浅了一分。有人醒来了。

> （你从河里，唤回 %d 人。）

> 河水满了一分。有人沉默了。

> （你让 %d 人，沉回河底。）

**文风注**：灵魂链把"复活/献祭"写成河水的水位变化（浅/满），是全系统最统一的自然词汇意象（河）；"有人醒来了/有人沉默了"以两句对称完成生死两向的播报，残酷处不着一字残酷。

> 记忆之语 Lv1 · 已醒来

> （旧梦在根间醒来。你仍记得它们。）

> 离开时，根仍听着大地。\n%d 分钟里：%s

离线收益项按实际正增量动态拼接：`日光 / 树液 / 生长 / 信仰 / 记忆 / <种族名>人口 +<数值>`。无正收益时不播报；摘要从 `GameManager` 取出后立即清空，同一加载过程只显示一次。
