# 化身观感（漂移镜子）

> 树的"漂移"（drift）系统叙事层：当记忆足够高（化身唤醒）、漂移值随时间与夺梦累计爬升时，树从"树"逐渐"漂"成"人"的镜子式观感文本。四档文本是玩家观察自己异化的窗口——像水边看倒影，越看越分不清。
> 来源：`features/memories/avatar_tiers.gd`（`TIERS` 数组，`text` 字段） | 归档日期：2026-09-01

触发与数值（来自 `features/memories/drift_actions.gd` + 本库字段）：

- **化身唤醒**：记忆 ≥ **30**（`AVATAR_MEMORY`）后化身面板开启（`is_avatar_awakened`）。
- 漂移值（drift）：`夺梦总次数 × 0.5 + max(记忆 − 30, 0) × 0.02 + drift_extra`，上限 10。
- 分档（`drift_tier`，实际判定含下界）：**tier 0** = drift < 3；**tier 1** = ≥ 3；**tier 2** = ≥ 6；**tier 3** = ≥ 9。下表 min/max 即源码标注的漂移值区间。
- 面板标题为 `化身 · <档名>`，档名：清醒 / 微漂 / 深漂 / 迷失（来自 `features/ui/main.gd`，见 09-ui-broadcast.md）。
- 原文照抄：均为单行文本，换行按源码保留（此处无换行）。

## 化身·第一档（tier 0，漂移值 0.0–3.0，清醒）

> 火塘边，你的影子晃了一下。像有个人，从树里探出头，又缩了回去。

## 化身·第二档（tier 1，漂移值 3.0–6.0，微漂）

> 影子的轮廓清晰了一些。它站在你旁边，树皮的纹理在它身上慢慢退去。

**文风注**：以"影子"为自我观察的介质——树没有镜子，只能借火光看自己的倒影；"树皮纹理退去"把异化写成渐变而非突变。

## 化身·第三档（tier 2，漂移值 6.0–9.0，深漂）

> 它的五官开始模糊。枝条从它的肩头长出来，它低头看了看，没有惊讶。

**文风注**："枝条从肩头长出来"是逆流——漂向人形的途中树性反噬；"它低头看了看，没有惊讶"一句把主体的坦然写尽，越是平静越惊心（留白不写尽）。

## 化身·第四档（tier 3，漂移值 9.0–10.0，迷失）

> 只剩一个人形的影子。它站在你的树影里，分不清谁是谁。你忽然想不起，它叫什么名字。

**文风注**："分不清谁是谁""想不起名字"是身份线的终极迷航，与明选·忒修斯（换了根须枝干还是不是那棵树）、图腾第五幅（你忘了你也是它）构成同一条暗线三处回声；"名字"二字落在全游戏最轻也最重的位置。
