# 图腾五幅

> 野民（wildfolk）苏醒后在石壁上刻画"树"的系列画作，随记忆值增长逐幅显现；玩家可"解读"（interpret）获得领悟（insight +1），解读文本渐进揭示**吞噬者真相**——这是夺梦暗线的主揭示链。
> 来源：`features/memories/totem_library.gd`（`TOTEMS` 数组，`reveal_text` / `interpret_text` 字段） | 归档日期：2026-09-01

触发与阈值（来自 `features/memories/totem_actions.gd`）：

- 图腾面板仅在**野民已苏醒**后可见（`visible_stage`）。
- 第 N 幅需**记忆 ≥ threshold** 才显形，threshold 即下表的记忆阈值 0 / 4 / 10 / 20 / 35。
- 「解读」按可见幅逆序进行（`next_interpretable`），每幅解读一次即标记，领悟 +1；觉醒播报为 `interpret_text + "\n（领悟 +1）"`（见 09-ui-broadcast.md）。
- 原文照抄，`\n` 已还原为换行；画幅文本在 UI 中显示为 `图腾·第 N 幅\n<reveal_text>`。

## 图腾·第一幅（记忆阈值 0）

> 石壁上多了一幅画。画的是一棵树——树冠遮天，根须伸进河流。河在变浅。

解读：

> 它们在画你。它们从第一天就在画你——你才知道，那不是风景，是证据。

## 图腾·第二幅（记忆阈值 4）

> 画里多了一行小人。跪在树前，黑黑的一排，像种子。

解读：

> 那是人。活过、哭过、把名字刻进石头的人。你仔细看——它们的脸，正对着你。

**文风注**："像种子"把跪伏的人群写成植物意象，既是野民视角，也暗合树的认知——人成了可播种之物；"脸正对着你"是凝视反转，恐怖藏在平静里。

## 图腾·第三幅（记忆阈值 10）

> 树的根须，缠着什么东西。像拥抱，又像收紧。

解读：

> 它们不画仇恨。它们只画事实。你吞下去的，不止是梦。

**文风注**："像拥抱，又像收紧"同一动作两个读法，把"吞噬"写温柔（柔和如风）又写警觉；"只画事实"把批判转给读者自己完成。

## 图腾·第四幅（记忆阈值 20）

> 画旁多了一双眼睛。不眨，看着你，已经看了很久。

解读：

> 那是野民的眼睛。也是你看自己的眼睛。中间没有隔着河。

**文风注**："中间没有隔着河"用地理意象写心理距离归零——树与"它者"的边界在此松动，为第五幅的合一点题。

## 图腾·第五幅（记忆阈值 35）

> 画的角落里，树的倒影里，站着一个人影。树与人影，是同一个。

解读：

> 你想起自己醒来时，手里那一点希望。它从来不是火种。是最后的证据——旧世界记得你，你忘了你也是它。

**文风注**：与遗迹·命运之泉同句互文（"醒来时手里那一点希望"）；"你忘了你也是它"是全游戏身份的终极回旋——树即旧世界遗民，"它/他们"的裂痕在此闭合。破折号后是全部真相。
