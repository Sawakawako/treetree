## T1：版本化元进度与持久化

**先写失败测试**

- `test_memory_archive_state.gd`：并集、去重、非法 id 过滤、真结局完整解锁、明选路径记录。
- `test_meta_save_manager.gd`：缺档、往返、版本字段、损坏主档回退备份。
- 扩充 `test_save_manager.gd`：`exists`、精确删除、版本字段、原有往返不回归。

**实现**

- 新增 `MemoryArchiveState` 与 `MetaSaveManager`。
- 为 JSON 存档补版本、临时写入和 `.bak` 回退。

**阶段门**：定向测试全绿；不得改动经营数值。

## T2：目录投影与结局文本解耦

**先写失败测试**

- `test_memory_archive.gd`：七类顺序、锁定态不泄露、已解锁正文、完整解锁计数。
- `test_ending_archive.gd`：四结局标题与正文保持 M6 已冻结文本。

**实现**

- 新增 `MemoryArchive`，把各资料库投影成统一条目。
- 新增 `EndingArchive`；`main.gd` 与图书馆共同读取，消除结局文案双份来源。

**阶段门**：全部现有资料 id 都能映射，锁定正文为空。

## T3：GameManager 生命周期与场景切换

**先写失败测试**

- 更新 `test_game_manager.gd`：启动迁移、返回标题保存、新轮保留馆藏、真结局清当前档并完整解锁。
- 验证标题期间不推进 tick、不自动生成新存档。

**实现**

- `GameManager` 持有元进度，统一捕获与保存。
- 新增继续、新轮、返回标题、进入主场景方法。
- `reset_to_title()` 改为真结局语义：归档、完整解锁、删当前档、切标题。
- 场景切换延迟到当前回调结束后执行。

**阶段门**：终局旧测试按新语义更新，当前周目和元进度互不串写。

## 风险与回滚

| 风险 | 护栏 |
|---|---|
| 标题页后台 tick 重建已删除存档 | 标题态关闭 `_process` 经营循环，主场景进入时再启用 |
| 新轮误删玩家进度 | 二次确认，只删除精确 `save.json`，保留 `.bak` 与 `meta.json` |
| 旧档见闻丢失 | 新版首次启动先捕获旧 `GameState`，再写 `meta.json` |
| 图书馆复制文案后漂移 | 目录只引用现有资料库；结局文本抽到共享 `EndingArchive` |
| 真结局未来新增内容不可见 | `library_complete` 作为全目录通行标记，不固化当前数量 |
