# 世界树 M5h 内容收尾设计

> **状态**：设计定稿，待按 `2026-09-05-m5-completion.md` 实施
> **日期**：2026-09-05
> **范围**：M5 半点制迁移、遗迹 5—9、体验机器、说书人④⑤⑥与彩蛋、记忆之语 Lv1、地脉感应/天光离线进度
> **边界**：终局、结局、多周目、九界、奇迹及二周目新增关系事件归 M6

---

## 一、设计目标

1. 补齐 M5 已存在但尚未闭环的内容入口；
2. 将关系变化统一缩放为半点制，保留 -3..+3 与亲密门槛 +2；
3. 让一周目可完成 10 点领悟，但关系最多 9/12，明确不能进入好结局；
4. 为 M6 提供稳定的 truth、insight、relations、choice_flags 与遗迹 flag；
5. 离线收益可测试、可封顶、不可重复领取，不在后台替玩家做选择。

## 二、冻结决策

### 2.1 关系半点制

| 来源 | 新值 |
|---|---:|
| 四族仪式互动 | 每族 +0.5 |
| 夺梦 3/6/9 次揭示 | 每级 -0.5，单族累计 -1.5 |
| 人族噩梦 | 采梦 -1 / 护梦 +1 |
| 护梦后的说书人故事④ | 人族 +0.5 |
| 诺恩·现在 | 救下 +0.5 / 放手 -0.5 |
| 菟丝子 | 松开 +1.5 / 继续 -1.5 |
| 忒修斯 B | 四族各 +0.5 |
| 体验机器 B | 四族各 +0.5 |
| 夺魂 | 每次 -1 |

- 存储、API、信号、条件解释器与 UI 全部使用 float，不得以 `int()` 截断 0.5；
- clamp 仍为 -3.0..3.0；亲密门槛仍为 2.0；
- 奥丁「献名字」不改变人族关系；删除主规格中孤立的旧 -1 描述。

### 2.2 周目语义（交给 M6 实现）

- `insight` 跨周目保留，同一知识 ID 整份存档只奖励一次；
- `relations` 与本周目关系事件完成标记进入新周目时清零；
- 一周目关系正向上限 9/12，不能进入好结局；
- 二周目新增石裔、野民各 3 个 +0.5 事件，当周可达 12/12；
- 三周目再次重建关系；三个周目的事件文本分别配置。

M5 不创建 `cycle_index` 或二周目事件空壳，只保证现有数据未来可迁移。

### 2.3 诺恩·现在

- A 必须在 `soul_river >= 2` 时才可选择；
- B 不改变 `soul_river`，删除「河底多了一缕」的数量暗示；
- 河底 100 缕表示本轮可调用的有限池，不记录全部自然死亡人口。

## 三、遗迹 5—9

### 3.1 数据契约

每个遗迹条目统一包含：

```gdscript
{
    "id": int,
    "name": String,
    "dream_text": String,
    "reward": Dictionary,
    "unlock": Dictionary,
    "flags": Array[StringName],
}
```

- 旧遗迹 1—4 迁移为相同结构，`reward` 保持记忆 +1，`unlock`/`flags` 可为空；
- `relics_found` 是发现事实源；flag 只服务跨模块语义，不替代遗迹 ID；
- 条件解释器至少支持 `relic_found`、`race_awakened`、`memory_gte`、`insight_gte`、`truth_gte`；
- 奖励解释器至少支持 memory、insight、truth；成功后一次性写 flag。

### 3.2 条目表

| ID | 名称 | 解锁 | 奖励与作用 |
|---:|---|---|---|
| 5 | 潘多拉遗迹 | 已发现 4；记忆 ≥20 | 记忆 +1；`pandora_found`；不增加希望 |
| 6 | 洞穴遗址 | 已发现 5；人族苏醒；记忆 ≥25 | 记忆 +1；`cave_found`；开放说书人④ |
| 7 | 梦想机 | 已发现 6；领悟 ≥5 | 记忆 +1；`dream_machine_found`；开放体验机器 |
| 8 | 天裂观测站 | 已发现 7；真相 ≥2 | 记忆 +1；真相 +2；`sky_rift_observed` |
| 9 | 环形废墟 | 已发现 8；真相 ≥4；记忆 ≥50 | 记忆 +1；领悟 +2；`circular_ruins_revealed` |

潘多拉不发希望：希望只按 M6 的结局弧线增长，不能由探索提前获得。

## 四、体验机器

### 4.1 触发

- choice id：`experience_machine`；
- 前置：已发现遗迹 7，或拥有 `dream_machine_found`；
- 一次性，完成后写入 `choices_done`。

### 4.2 三选项

| 选项 | 后果 | flag |
|---|---|---|
| A 开启 | 信仰 -50 | `experience_opened` |
| B 毁掉 | 四族关系各 +0.5 | `experience_destroyed` |
| C 研究 | 领悟 +1 | `experience_studied` |

B 不附带领悟；C 不附带关系。信仰不足 50 时 A 灰显，不能把信仰扣成负数。

## 五、说书人④⑤⑥与彩蛋

### 5.1 状态

- `storyteller_stories: Array[StringName]`：已完成的主线故事；
- `storyteller_extras: Array[StringName]`：已完成彩蛋；
- 两者均为集合语义，存档时过滤非法值；
- 领悟奖励另写跨周目知识 ID，M6 重演文本时不得重复加点。

### 5.2 触发链

| 内容 | 条件 | 一次性奖励 |
|---|---|---|
| 故事④ | `cave_found` + `human_nightmare_protected` | 人族关系 +0.5 |
| 故事⑤ | 已听④ + 人族关系 ≥2 + 领悟 ≥5 | 无 |
| 故事⑥ | 已听⑤ + `sky_rift_observed` + 真相 ≥4 | 领悟 +1 |
| 小溪与激流 | 已听④ + 人族关系 ≥2 | 无；不阻塞主线 |

故事④的 +0.5 与护梦的即时 +1 分开结算。配合人族仪式 +0.5，恰好达到亲密门槛 2。

## 六、领悟预算与记忆之语

### 6.1 最低知识路线

```text
图腾 5
+ 环形废墟 2
+ 说书人故事⑥ 1
= 8
+ 忒修斯 C 2
= 10（好结局领悟门槛）
```

体验机器 C 的 +1 是可选余量，不承担忒修斯 C 的前置。

### 6.2 记忆之语 Lv1

- 解锁条件：记忆 ≥500、领悟 ≥5；
- 成功升级：只消耗 500 记忆，领悟保持不变；
- 5 点领悟是知识门槛，不是货币；
- 已达 Lv1 后不可重复购买。

若消耗 5 点领悟，现有路线无法可靠补回好结局所需的 10 点，因此禁止消费。

## 七、离线进度

### 7.1 解锁和时间

- 地脉感应解锁离线结算；
- `last_saved_unix` 缺失或首次存档时只记录时间，不补发；
- 普通有效时间：`min(real_elapsed, 8h)`；
- 天光有效时间：`min(real_elapsed * 2, 8h)`；
- 负时间差归零，同一时间段只能结算一次。

### 7.2 结算范围

结算：树液、生长、信仰、记忆、已购引擎与设施产出、非致死人口增长。

不结算：叙事事件、明选、人口死亡、资源兑换、购买、自动消费。

种族参与供养与产出；供养不足时该族产出和人口增长冻结。离线计算复用在线公式，系统时钟由外层注入，纯逻辑不得直接读取当前时间。

## 八、实现边界

M5 包含：

- 关系 float 迁移及既有数值同步；
- 遗迹 5—9；
- 体验机器；
- 说书人④⑤⑥与彩蛋；
- 记忆之语 Lv1；
- 地脉感应、天光和离线结算。

M6 包含：

- 世界之语、九界、奇迹、终局与多周目；
- 关系周目清零；
- 二周目六个新增关系事件；
- 三个周目的事件文本差分；
- 跨周目知识 ID 防重复账本。

## 九、验收要点

1. 遗迹 5—9 无法越过门槛连续挖出，奖励和 flag 只发一次；
2. 潘多拉不改变希望；
3. 一周目全正向关系路线为人族 3、林地民 3、石裔 1.5、野民 1.5，总计 9；
4. 最低知识路线可在忒修斯 C 后达到 10；
5. 记忆之语升级后领悟不下降；
6. 离线收益 8 小时封顶，首存不补发，天光先乘时间再封顶；
7. 离线结算不触发任何需要玩家选择的内容；
8. 旧整数关系存档无损读取，新 0.5 值可无损往返；
9. M5 不出现可操作的 M6 空壳入口。
