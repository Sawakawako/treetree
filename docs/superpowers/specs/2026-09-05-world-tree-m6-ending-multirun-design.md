## 〇、设计目标与铁律

M6 把游戏从「无限增量」拧成「三周目叙事循环」：

1. **一周目默认坏结局**（糊涂）：玩家体验「复苏—吞噬—不知所以然」的完整弧线，为二周目埋伏笔。
2. **二周目选项分支**：关系满 → 好结局；不满 → 普通结局。好结局 +1 希望。
3. **三周目浓缩快进 + 真结局**（希望≥2）：隐藏选项亮起，「把希望用在自己身上」——记得一切的树，还活着的树。

**铁律（来自 spec 已拍板，M6 不重发明）：**

| 规则 | 来源 |
|---|---|
| 四结局 = 领悟 × 羁绊 × 希望 矩阵 | spec §8.2 |
| 一周目关系正向上限 9/12（自然正源不足），不能好结局 | spec §8.4（2026-09-05 修订） |
| 二周目新增 6 关系事件（石裔3+野民3，各 +0.5），当周可重建至 12/12 | 主人拍板 2026-09-05 |
| 领悟跨周目保留；同一知识 ID 只奖励一次 | spec §8.6 / §13.6 |
| 关系值 + 关系事件完成标记每周目清零 | spec §8.6 |
| 希望 = 唯一跨周目货币（1 开局 → 好结局+1 → 真结局耗 2） | spec §8.5/§14.5 |
| 归还序列 7 步状态机（好结局完整 7 步 / 普通坏拆 4-5 步停 / 真结局不拆） | spec §8.3 |
| 三周目浓缩快进周目（开局资源赠予式快进，主人拍板） | spec §8.6 + 拍板 |
| 归还序列文本每周目全套差分（3 周目 × 7 步） | 主人拍板 2026-09-05 |
| 真结局 = 结束循环回标题（不做自由模式） | 主人拍板 2026-09-05（偏离 spec §8.5 原案，见 §六） |

## 一、终局触发（M6-A1）：里程碑门 + 明选常驻

**决策（主人拍板）**：终局不是「资源耗尽」（纯增量资源难尽），而是**世界之轴成型里程碑 + ⑦明选常驻**。

### 1.1 世界之轴成型条件

终局明选⑦「凝记忆为希望」出现的条件（世界之轴 = Yggdrasil 完整形态，spec §13.10）：

```
世界之轴成型（全部满足）：
  1. 环形废墟已发现（relic 9，终局揭示入口 —— 树是旧世界幸存者最后的梦）
  2. 四族全部唤醒
  3. 明选 ①—⑥ 已全部完成（choices_done 含 6 张）
  4. 说书人最终故事已听完（storyteller_stories 全）
  5. 树高 growth ≥ 终局阈值（数值建议见 §1.3，主人试玩可调）
```

成型后 UI 出现常驻「世界之轴」入口（明选⑦），玩家**主动选择**何时进入终局——增量玩法不停，终局由玩家意志触发（呼应「世界之轴 = 连接生死天地的自觉」）。

### 1.2 触发即停顿点

- 进入世界之轴 → 触发明选⑦（四路径），复用 M5g ChoiceLibrary/ChoiceActions 机制（choices.json 加 ⑦ 卡片）。
- 明选⑦ 是**停顿点**：无倒计时，占用 `_pending_choice`，选完进入对应结局路径。

### 1.3 数值建议（试玩可调，标记估值）

| 项 | 建议值 | 依据 |
|---|---|---|
| growth 终局阈值 | 1000（tree_canopy 系满级后可及） | 巨树 30→100 记忆觉醒后，中后期节奏 |
| 希望开局 | 1（现状已 1） | spec §14.5 |
| 结局判定时点 | 明选⑦ 选完即判定 | spec §8.2 |

## 二、终局明选⑦ 四路径（M6-A2）

复用 M5g 引擎，`data/choices.json` 新增卡片 `world_axis`。四路径 = 明选⑦ 的四个选项，但**判定逻辑在终局状态机（ending/）而非 ChoiceActions**（选项只设意图 flag，终局状态机消费）。

```
⑦ 世界之轴 · 四路径选项：
  a. 「凝记忆为希望」   → 普通/坏结局线（判定看领悟与羁绊）
  b. 「拒绝」           → 坏结局线·虚无变体（无领悟也拒绝凝希望——文本差分）
  c. 「把记忆还给河」   → 好结局线（归还序列 7 步；羁绊不足则落普通结局）
  d. 「……」            → 真结局（隐藏选项：三周目 + 领悟满 + 关系满 + 希望≥2 才亮）
```

**结局类型**：bad（坏）/ normal（普通）/ good（好）/ true（真）。b 的「拒绝」不单列结局类型——它落 bad，仅以虚无差分文本区分（spec §8.3「凝成一点希望 vs 什么都不凝」）。

## 三、四结局判定（M6-A3）：领悟 × 羁绊 × 希望

### 3.1 判定矩阵（spec §8.2 权威，M6 落地）

| 结局 | 领悟(≥10) | 羁绊(四族关系满 12/12) | 希望 | 触发路径 | 循环？ |
|---|---|---|---|---|---|
| **坏** | ✗ | ✗ | 1 | 明选⑦ a/b 无领悟 | 循环（无意识） |
| **普通** | ✓ | ✗ | 1 | 明选⑦ a/b 有领悟 或 c 但羁绊不足 | 循环（有意识） |
| **好** | ✓ | ✓ | 1 | 明选⑦ c + 双满 | 终止 |
| **真** | ✓ | ✓ | 2 | 明选⑦ d | 超越 |

### 3.2 与 spec 的衔接澄清

- **「把记忆还给河」但羁绊不满** → 判定为普通结局（领悟够、不被爱，「没有足够的理由留下，也没有足够的爱去放下」spec §8.2）——归还序列拆到一半停下（spec §8.3：普通/坏拆 4-5 步停）。
- **好结局门槛**：领悟 ≥10（四族各 3 = 12/12）——**好结局只能二周目达成**（一周目 9/12 上限，见 §四）。

### 3.3 希望点结算（终局状态机执行）

| 结局 | 希望变更 | 下一周目希望 | 结算画面展示 |
|---|---|---|---|
| 坏 / 普通 / 拒绝 | +0 | 1 | 显示「希望：1」不变 |
| 好 | **+1** | 2 | 显示「希望长了一点：1 → 2」 |
| 真 | 消耗（圆满了，循环终止） | — | 不展示希望变化（无下一周目，突出「用在自己身上」） |

## 四、周目门控与关系上限（M6-B1）

**决策（主人拍板）**：「一周目关系上限 9/12」**不用显式 cap 逻辑**，用**事件周目门控**自然实现：

### 4.1 周目门控表

| 内容 | 一周目 | 二周目 | 三周目 |
|---|---|---|---|
| 既有仪式互动（四族各 +0.5） | ✅ | ✅ | ✅ |
| 既有明选正源（护梦/诺恩/菟丝子/忒修斯B/体验B/说书人④） | ✅ | ✅ | ✅ |
| 石裔新事件 ×3（各 +0.5） | ❌ 不出现 | ✅ | ✅ |
| 野民新事件 ×3（各 +0.5） | ❌ 不出现 | ✅ | ✅ |
| 关系上限（自然） | 9/12（3+3+1.5+1.5） | 12/12 | 12/12 |

> `run_number`（周目数）为 GameState 新字段，事件可用性按 `run_number >= 2` 判定。

### 4.2 一周目各族可达关系核算（校验，主人确认）

| 族 | 正源清单（一周目） | 合计 | clamp |
|---|---|---|---|
| 人族 human | 仪式+0.5、护梦+1.0、忒修斯B+0.5、体验B+0.5、说书人④+0.5 | **+3.0** | +3.0 |
| 林地民 forestfolk | 仪式+0.5、诺恩现在A+0.5、菟丝子A+1.5、忒修斯B+0.5、体验B+0.5 | **+3.5** | +3.0 |
| 石裔 stoneborn | 仪式+0.5、忒修斯B+0.5、体验B+0.5 | **+1.5** | +1.5 |
| 野民 wildfolk | 仪式+0.5、忒修斯B+0.5、体验B+0.5 | **+1.5** | +1.5 |

四族和 = 3+3+1.5+1.5 = **9/12** ✓ 自然达成 spec「一周目不能好结局」。

### 4.3 人族顺序陷阱（主人拍板：保持严格顺序）

人族满 +3 需**特定明选顺序**：护梦(+1) → 仪式(+0.5) = 1.5 → 说书人④ 需关系≥+2 → 须先忒修斯B(+0.5) 或体验B(+0.5) 补到 ≥2 → 说书人④(+0.5) → +3。
- 这是**设计意图**（选择有代价：人族好结局路线要求玩家对每张牌都选「温柔」答案）。
- 文档记录为「人族好结局路线的最小温柔序」：护梦 → 忒修斯「我不知道」→ 说书人④（或体验机器拔根替代补 0.5）。

### 4.4 二周目新增 6 事件（石裔 3 + 野民 3）

**决策（主人拍板）**：石裔 3 个 + 野民 3 个，各 +0.5，二周目（run≥2）出现，补足两族到 +3 → 四族 12/12。

**机制形态**（沿用 RelationEvents 一次性互动模式，但周目门控）：
- 每族 3 个事件 = 3 个独立事件位，各 +0.5，各自一次性，触发后入 `relation_events`。
- 事件可用条件 = 该族唤醒 + 资源条件 + `run_number >= 2` + 未触发。
- 内容方向：二周目「你记得」主题——石裔/野民认出「这棵树回来过」。

**内容（文风六则，具体文本在设计附录定稿）**：
- 石裔 3：① 石裔梦见上一轮的刻痕（它们记得你的形状）；② 石裔献上一块「你上次折断的根须」做的碑；③ 石裔问：「母树，你这次还会走吗？」
- 野民 3：① 野民在你脚下画了一幅「上一轮的树」；② 野民首领说「图腾上的眼睛，见过你两次」；③ 野民把「你曾还给河的记忆」编进了歌。

> 注：文本最终稿以设计文档附录（文风六则自检后）为准，实施前过 humanize-ai。

## 五、周目切换与重置（M6-B2）

**决策（主人拍板）**：结算后一键再醒（结局画面 → 结算 → 「再次醒来」按钮 → 直接下一周目开局文本）。

### 5.1 周目切换流程

```
终局明选⑦ 选定 → 结局路径（归还序列/最终画面）
  → 结算画面（结局判定播报 + 希望点变更 + 领悟/知识保留清单）
  → [再次醒来]（唯一按钮）
  → 周目重置 + 开局文本层叠 → 新周目开始
```

- 真结局：结算后**无**「再次醒来」→ 循环终止，回标题（主人拍板，见 §六）。

### 5.2 周目重置规则（记忆余烬 = 仅保留知识与解锁，主人拍板）

**跨周目保留（余烬）：**
- `hope`（希望点）
- `insight`（领悟值，跨周目累积；同一知识只奖一次——需知识 ID 表去重）
- `truth`（真相值）
- 知识/彩蛋解锁标记：`totem_interpreted`、`storyteller_stories`、`choice_flags`（知识型，如 `theseus_remembered`）
- 记忆图书馆完整度标记（若已解锁）

**每周目清零：**
- 所有资源（daylight/sap/growth/memory/faith）
- 所有等级（leaf/branch/root/chloroplast/xylem/…/lingua/seedling/设施/引擎）
- `races`（人口/唤醒状态）
- `relations` + `relation_events`（关系与事件完成标记）
- `intimate_events`、`plundered`、`plunder_reveals`
- `choices_done`、`soul_river`（归 100）
- 遗迹 `relics_found`、根须 `root_depth`
- `run_number` +1

**实现要点**：重置 = 新建 GameState 快照 + 仅拷贝保留字段（或 GameState 增加 `new_run_preserved()` 工厂）。

### 5.3 周目文本层叠（spec §8.6 权威）

| 周目 | 开局文本附加 |
|---|---|
| 一周目 | 原始开局 |
| 二周目 | 「你记得这缕光。你曾把它交给下一个自己。」 |
| 三周目 | 「你醒来时，手里有一点希望。不是'一点'——是一点半。…那是你的形状。」 |

## 六、真结局（M6-C1）：判定 + 隐藏选项 + 循环终止

**决策（主人拍板）**：真结局达成 = **结束循环回标题**（偏离 spec §8.5 原案「记忆图书馆自由模式」——主人选择更收束的完结感）。

### 6.1 触发条件（spec §8.5 权威 + 拍板）

```
三周目（run_number >= 3）
+ 领悟值满（≥10）
+ 关系值满（12/12）
+ 希望 ≥ 2（即二周目达成过好结局 +1）
→ 终局明选⑦ 隐藏选项 d「……」亮起
```

> spec §8.5 说「领悟值满 + 关系值满」——领悟满 = ≥10（好结局门槛同值，最小路线图腾5+环形2+说书人1+忒修斯C2=10 见 spec §13.6）。二周目普通结局（未好）则希望仍 1 → 三周目选项为暗（spec 原文）。

### 6.2 真结局最终画面（spec §8.5 权威文本）

> **「把希望用在自己身上。」** 你第一次把希望对准自己。记忆没有还回河里——你留下了它们。
> 你记得一切：你是幸存者的灵魂，旧世界因何而亡，你做过的一切。
> 树没有倒下。根须深入冥河，树冠刺破天界——你站在那里，**记得一切的树，还活着的树。**
> 四族抬头望你："母树，你记得了。""我记得。而我还想活着。"

### 6.3 循环终止（偏离 spec 的记录）

- spec §8.5 原案：真结局后解锁记忆图书馆自由模式（20 遗迹 + 全部故事 + 彩蛋）。
- **主人拍板（2026-09-05）**：真结局后结束循环回标题，不做自由模式。
- 记忆图书馆内容作为**重读画廊**保留（标题界面可进），但无自由增量模式。
- 偏离理由记录：真结局「记得一切、还想活着」的超越态，用「结束循环」的收束比「无限自由模式」更有完结重量；也避免自由模式与增量玩法目标冲突。

## 七、归还序列（M6-A4）：7 步状态机 + 周目差分

**决策（主人拍板）**：
1. 交互形态 = 逐步点击推进（每步点「归还」看文本，7 步完成）。
2. 文本 = 每周目全套 7 步差分（3 周目 × 7 步 = 21 段）。

### 7.1 状态机

`features/ending/return_sequence.gd`（RefCounted 纯逻辑，可 headless 测）：
- 状态：`step 1..7`（step 0 = 未开始，step 8 = 完成）
- `advance()` → step+1，返回该步文本（按 `run_number` 取差分版）
- 拆解差异（spec §8.3）：好结局走满 7 步；普通/坏走 4-5 步后触发「忽然舍不得」文本停步（不再推进）；真结局不进归还序列（走最终画面）。
- 归还中数字镜像：树解体度 ↑ / 世界复苏度 ↑，相加恒 100%（UI 表达，纯显示层）。

### 7.2 7 步文本锚点（spec §8.3 权威，M6 做差分扩展）

| 步 | 归还 | 锚点（一周目版） | 差分方向 |
|---|---|---|---|
| 1 | 枝冠 | 你把叶子和光一起放下。树冠低了，天空重了一点。 | 二周目「你记得这些叶子」/三周目带希望 |
| 2 | 枝干 | 你拆下每一根枝。它们落进土里，变成别的树的骨架。 | 同上 |
| 3 | 根须 | 你把根须一根一根从河里拔出来。河面泛起细小的涟漪——像告别。 | 同上 |
| 4 | 年轮 | 年轮一圈一圈松开。每一圈，都是你活过的一年。 | 同上 |
| 5 | 灵魂 | 你把捞起的灵魂轻轻放回河底。它们下沉的时候，没有挣扎。 | 同上 |
| 6 | 希望 | 最后，你低头看那点希望。你没有凝成什么——你把它种进了土壤。 | 三周目「多一点」呼应 |
| 7 | 成为种子 | 你看着自己。你不再是树了。你是一颗种子。… | 周目差分收束 |

> 完整 21 段文本在**附录 A**（文风六则，写作任务完成后过 humanize-ai）。

## 八、架构落地（features/ending/ + GameState 扩展）

### 8.1 新增目录 features/ending/（spec §15 features/ending/ 权威）

```
features/ending/
  ending_state_machine.gd   # 终局状态机：判定结局路径/触发归还序列/结算希望
  return_sequence.gd        # 归还序列 7 步状态机（纯逻辑 RefCounted）
  ending_text.gd            # 结局文本库（四结局 + 归还 21 段差分 + 周目开局层叠）
  (后续 M6-D：九界/世界之语/奇迹 落这里或 features/world/)
```

### 8.2 GameState 扩展

```gdscript
# M6 新增字段
var run_number: int = 1        # 当前周目（1 起始）
var ending_seen: Array[StringName] = []   # 已达成结局 id（多周目成就/结算用）
```

- `to_dict/from_dict` 序列化 + 缺省回退（沿既有防御模式）。
- `run_number` 是周目门控（石裔野民事件）与文本层叠判定的依据。

### 8.3 GameManager 集成（沿既有信号模式）

```
signal ending_started            # 进入终局明选⑦
signal ending_resolved(outcome)  # 结局判定完成（bad/normal/good/true）
signal run_restarted             # 周目重置完成

func start_world_axis() -> void   # 检测世界之轴成型 → 弹明选⑦
func resolve_ending(choice)       # 消费明选⑦选项 → 判定 → 结算希望
func restart_run() -> void        # 周目重置（保留余烬字段）→ 开局
```

### 8.4 与既有系统的边界

- 明选⑦ 卡片数据进 `choices.json`（文本外置惯例），但**后果不写在 effects**（终局判定复杂，走 EndingStateMachine，选项只设 intent flag）。
- 二周目六事件走既有 RelationEvents 一次性模式 + `run_number` 门控（不新建机制）。
- 归还序列纯 RefCounted 逻辑，headless 可测。
- UI：世界之轴入口按钮（成型后 visible）、归还序列面板（7 步逐步点击）、结算画面、开局文本层叠。
